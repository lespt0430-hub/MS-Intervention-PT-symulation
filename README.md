# 근골격계 물리치료 가상환자 시뮬레이션

광주보건대학교 물리치료학과 실습교육용 3D 시뮬레이션.
JOSPT 임상진료지침(CPG) 영문 원본 기반 가상환자 12명을 문진 → 이학적 검사 → 진단 → 치료계획 순으로 진료하고, 단계별 채점과 CPG 근거 피드백을 받습니다. (질환 CPG 12종 + ACL 부상 예방 CPG·비수술 재활 가이드라인 통합 반영)

## 실행 방법

**웹 주소로 여는 것을 권장합니다.** GitHub Pages 배포 절차는 [DEPLOY.md](DEPLOY.md) 참고.

로컬에서 확인만 할 때는 이 폴더에서 간단한 서버를 띄웁니다:

```bash
python -m http.server 8000
```

→ 브라우저에서 `http://localhost:8000`

이름 입력 → 문진 방식 선택 → 화질 선택 → **물리치료실 입장**

> `index.html`을 그냥 더블클릭(`file://`)해도 대개 열리지만, 앞으로 3D 모델
> (`.glb`)이나 실습실 스캔을 추가하면 브라우저 보안 정책에 막힙니다.
> 처음부터 웹 주소로 운영하는 것이 안전합니다.
>
> Three.js는 `vendor/three-lib.js`로 함께 배포되므로 **외부 CDN에 의존하지
> 않습니다.** 내장 답변 모드는 인터넷 없이도 동작합니다.

## 문진 방식 (2가지 모드)

| 모드 | 설명 | 준비물 |
|---|---|---|
| **내장 답변 모드** (기본) | 환자 데이터에 저장된 답변을 키워드 매칭으로 제공. 채점도 키워드 기반 | 없음 (무료) |
| **AI 문진 모드** | Google Gemini와 실시간 자유 대화로 문진. 채점도 AI 평가 | 교수 모드에서 Gemini API 키 등록 |

### 교수 모드 (AI 연동 설정)

시작 화면 하단 **⚙ 교수 모드**에서 Gemini API 키를 등록합니다.
[aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 무료 발급 가능하며, 실습실 PC에 한 번 등록하면 그 PC의 모든 학생이 AI 문진 모드를 사용할 수 있습니다 (키는 해당 PC의 localStorage에만 저장).

## 조작법

| 키 | 동작 |
|---|---|
| 화면 클릭 | 이동 모드 시작 (마우스 시점 잠금) |
| W A S D / 방향키 | 이동 |
| 마우스 | 시점 회전 |

## 화질 설정

시작 화면에서 고를 수 있고, 선택은 그 PC에 저장됩니다.

| 등급 | 내용 | 대상 |
|---|---|---|
| **자동** (기본) | GPU를 판정해 등급을 정하고, 실행 중 fps가 떨어지면 한 단계 낮춘다 | 권장 |
| **낮음** | 점광원 조명, 그림자 1024, 후처리 없음 | 사무용 내장 그래픽 |
| **보통** | 면광원(형광등 패널), 그림자 2048, SMAA | 보급형 외장 GPU |
| **높음** | + 주변광 차폐(GTAO), 형광등 빛번짐(블룸), 바닥 반사 | GTX/RTX 등 |

색관리·실내 환경광·PBR 표면 질감은 **모든 등급에 동일하게** 적용됩니다.
등급에 따라 달라지는 것은 해상도·그림자 품질·광원 종류·후처리뿐이므로,
낮음에서도 재질감은 그대로입니다.

## 진료 흐름

1. **문진** — 환자와 자유 대화(AI). 발병 시기, 악화/완화 요인, 적신호 선별 등 핵심 항목을 직접 질문해야 점수 획득.
2. **이학적 검사** — 검사 버튼을 눌러 시행. 필수검사 누락·불필요 검사 남발이 채점에 반영.
3. **진단** — 감별진단 목록에서 선택.
4. **치료계획** — 중재 다중 선택. CPG 권고등급(A/B/C) 가중, 비권고 중재 선택 시 감점.
5. **채점** — 40점 만점 리포트. 12명 완료 시 종합 성적표(다운로드/인쇄 가능).

## 비용 안내

- **내장 답변 모드**: 완전 무료.
- **AI 문진 모드**: Gemini 2.5 Flash 무료 할당량 내에서 대부분 무료. 유료 전환 시에도 환자 1명당 수 원 미만.

### 그래픽 구조

`render.js`가 빛과 재질을, `game.js`가 공간과 물체를 담당합니다.
장비를 추가할 때는 `game.js`의 `buildDecor()`만 건드리면 되고,
조명이나 화질을 조정할 때는 `render.js`의 `PRESETS`만 보면 됩니다.

바닥·벽·천장·커튼 질감은 외부 이미지 파일이 아니라 **실행 시점에 캔버스로
그려서 노멀맵·러프니스맵까지 생성**합니다(`RENDER.pbrMaterial`).
덕분에 추가 다운로드가 0바이트이고, 색이나 무늬를 바꾸려면 그리는 함수의
숫자만 고치면 됩니다.

**바닥 반사**(높음 화질)는 장면을 한 번 더 그려 뒤집어 붙이는 실제 평면
반사입니다(`RENDER.buildFloorReflection`). 환경맵만으로는 "무엇이 비치는지"가
표현되지 않아, 참고 사진 속 폴리싱 에폭시 바닥의 느낌이 나오지 않습니다.
거울이 되지 않도록 알파로 얹고 프레넬을 적용해 **비스듬히 볼수록 강해집니다.**
프레임 비용은 약 15%이며, fps가 떨어지면 자동 강등에서 가장 먼저 꺼집니다.

### 참고 자료

실내 구성은 국내 재활병원 치료실 사진·렌더링 3장을 기준으로 맞췄습니다
(제3자 저작물이므로 저장소에는 포함하지 않습니다 — `.gitignore` 참고).
커튼 부스의 목재 각기둥·가로보 구조와 부스 번호판, 주황 인조가죽 치료대,
바닥의 빨강·노랑 이중선 타원 보행 트랙, 광택 바닥이 여기서 왔습니다.

## 환자 데이터 수정

`patients1.js`, `patients2.js`에서 환자 시나리오(persona), 검사 결과, 진단 선택지, 치료 중재와 권고등급을 자유롭게 수정할 수 있습니다. 형식만 유지하면 환자 추가도 가능합니다(베드는 12개 기준 배치 — 2열×6개).

## 주의

- Gemini API 키는 브라우저 localStorage에만 저장됩니다. 공용 PC 철수 시 교수 모드의 "연동 해제" 또는 브라우저 데이터 삭제를 권장합니다.
- 교육용 시뮬레이션이며 실제 임상 판단을 대체하지 않습니다.
