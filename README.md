# 근골격계 물리치료 가상환자 시뮬레이션

광주보건대학교 물리치료학과 실습교육용 3D 시뮬레이션.
JOSPT 임상진료지침(CPG) 영문 원본 기반 가상환자 12명을 문진 → 이학적 검사 → 진단 → 치료계획 순으로 진료하고, 단계별 채점과 CPG 근거 피드백을 받습니다. (질환 CPG 12종 + ACL 부상 예방 CPG·비수술 재활 가이드라인 통합 반영)

## 실행 방법

1. `index.html`을 **더블클릭**하여 브라우저(크롬/엣지 권장)에서 엽니다.
   - 인터넷 연결 필요 (Three.js CDN 로딩 · AI 모드 사용 시 Gemini API)
2. 이름 입력 → 문진 방식 선택 → **물리치료실 입장**

## 문진 방식 (2가지 모드)

| 모드 | 설명 | 준비물 |
|---|---|---|
| **내장 답변 모드** (기본) | 환자 데이터에 저장된 답변을 키워드 매칭으로 제공. 채점도 키워드 기반 | 없음 (무료) |
| **AI 문진 모드** | Google Gemini와 실시간 자유 대화로 문진. 채점도 AI 평가 | 교수 모드에서 Gemini API 키 등록 |

### 교수 모드 (AI 연동 설정)

시작 화면 하단 **⚙ 교수 모드**에서 Gemini API 키를 등록합니다.
[aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 무료 발급 가능하며, 실습실 PC에 한 번 등록하면 그 PC의 모든 학생이 AI 문진 모드를 사용할 수 있습니다 (키는 해당 PC의 localStorage에만 저장).

## 조작법

| 키 | 동작 |
|---|---|
| 화면 클릭 | 이동 모드 시작 (마우스 시점 잠금) |
| W A S D / 방향키 | 이동 |
| 마우스 | 시점 회전 |
| E | 근처 환자 진료 시작 |
| ESC | 이동 모드 해제 |

## 진료 흐름

1. **문진** — 환자와 자유 대화(AI). 발병 시기, 악화/완화 요인, 적신호 선별 등 핵심 항목을 직접 질문해야 점수 획득.
2. **이학적 검사** — 검사 버튼을 눌러 시행. 필수검사 누락·불필요 검사 남발이 채점에 반영.
3. **진단** — 감별진단 목록에서 선택.
4. **치료계획** — 중재 다중 선택. CPG 권고등급(A/B/C) 가중, 비권고 중재 선택 시 감점.
5. **채점** — 40점 만점 리포트. 12명 완료 시 종합 성적표(다운로드/인쇄 가능).

## 비용 안내

- **내장 답변 모드**: 완전 무료.
- **AI 문진 모드**: Gemini 2.5 Flash 무료 할당량 내에서 대부분 무료. 유료 전환 시에도 환자 1명당 수 원 미만.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 메인 페이지 (학생 입장 + 교수 모드) |
| `game.js` | 3D 물리치료실 (Three.js — 질환별 자세 환자, 치료 장비) |
| `ui.js` | 진료 UI·채점·리포트 |
| `api.js` | 문진 엔진 (내장 답변 모드 + Gemini API 연동) |
| `patients1.js` / `patients2.js` | 가상환자 12명 데이터 (CPG 기반, 내장 답변 포함) |
| `exams.js` | 부위별 이학적 검사 라이브러리 |
| `PROMPT_DESIGN.md` | 프롬프트 설계 문서 |

## 환자 데이터 수정

`patients1.js`, `patients2.js`에서 환자 시나리오(persona), 검사 결과, 진단 선택지, 치료 중재와 권고등급을 자유롭게 수정할 수 있습니다. 형식만 유지하면 환자 추가도 가능합니다(베드는 12개 기준 배치 — 2열×6개).

## 주의

- Gemini API 키는 브라우저 localStorage에만 저장됩니다. 공용 PC 철수 시 교수 모드의 "연동 해제" 또는 브라우저 데이터 삭제를 권장합니다.
- 교육용 시뮬레이션이며 실제 임상 판단을 대체하지 않습니다.
